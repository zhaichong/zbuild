运行环境安装恢复指引

本工具首次使用需要下载 Python 运行环境（构建任务还需要 Node 14）。如果自动下载一直失败，可按下列方式恢复。

方式一：重试

返回工具窗口点击「重试」。工具会按 manifest 中的主源 / 备用源依次尝试。

方式二：手动放置运行环境（推荐离线场景）

目标目录：

%LOCALAPPDATA%\zbuild\runtime\python
  1. 在其它有网络的电脑上运行 tools\setup_runtime.ps1，或从发版方获取 zbuild-python-3.11.9-win-x64.zip（须与当前安装包内 manifest 的 SHA256 一致）。
  2. 将 ZIP 解压到上面的 python 目录，保证存在： python\python.exe、python\Lib\site-packages\openpyxl、python\Lib\site-packages\paramiko。
  3. 必须写入完成标记 .ready.json（与安装包内 electron/runtime-manifest.json 的 python.version / python.sha256 完全一致），例如：
{
  "name": "python",
  "version": "3.11.9",
  "sha256": "<与安装包 manifest 中 python.sha256 相同的 64 位十六进制>",
  "installedAt": "2026-01-01T00:00:00.000Z"
}

文件路径：

%LOCALAPPDATA%\zbuild\runtime\python\.ready.json
仅解压、不写 .ready.json，或 version/sha256 与当前安装包不一致时，工具不会视为已安装，仍会尝试联网下载。 启动时还会做健康检查：Python 3.11.9，且 openpyxl==3.1.5、paramiko==5.0.0。

方式三：配置下载镜像（仅覆盖前缀）

编辑：

%LOCALAPPDATA%\zbuild\runtime-config.json 
{
  "mirrorBase": "https://your-https-mirror.example.com/zbuild-runtime"
}

镜像必须以 https:// 开头。工具会请求 {mirrorBase}/{manifest.path}：

  • Python：.../zbuild-python-3.11.9-win-x64.zip（须由你们自己托管该文件）
  • Node：路径形如 node/v14.21.3/node-v14.21.3-win-x64.zip（可用兼容 npmmirror 布局的源）
不要把 Node 的 npmmirror 前缀直接当作 Python 源：npmmirror 默认没有 zbuild 预制 Python ZIP。

版本、文件名与 SHA256 无法通过配置修改，只能换下载主机前缀。

方式四：系统 Python / Node 紧急覆盖（逃生口）

仅在自动安装与手动放置都不可用时使用。编辑：

%LOCALAPPDATA%\zbuild\runtime-config.json 
{
  "overridePython": "C:\\Path\\To\\python.exe",
  "overrideNode": "C:\\Path\\To\\node.exe"
}

工具会校验：

  • Python：版本为 3.11.9，且可 import openpyxl, paramiko 且版本分别为 3.1.5 / 5.0.0
  • Node：版本为 14.21.3，且同目录下 npm 可用（Node 14 自带 npm 6.x）
不满足上述条件时覆盖会被清除，不会静默使用错误运行时。

以上任一种方式完成后，请重新打开工具。
