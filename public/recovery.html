运行环境安装恢复指引

本工具首次使用需要下载 Python 运行环境。如果自动下载一直失败，可以按以下任一种方式手动恢复。

方式一：重试

返回工具窗口点击「重试」。工具会自动切换备用下载源。

方式二：手动放置运行环境

运行环境会安装到如下目录：

%LOCALAPPDATA%\zbuild\runtime\python
  1. 在其它有网络的电脑上，运行项目提供的 tools\setup_runtime.ps1，或在发版方处获取预制压缩包 zbuild-python-3.11.9-win-x64.zip。
  2. 将压缩包解压后整体放到上面的 python 目录（目录结构需保留：python\python.exe、python\Lib\site-packages 等）。
  3. 重新启动本工具。若手动放置成功，工具会直接使用，不再要求下载。
手动放置不会写入完成标记。工具启动时会做健康检查（要求可导入 openpyxl、paramiko）与版本校验（Python 3.11.x），不满足时会重新尝试下载。

方式三：配置自定义镜像

如果默认下载源在你的网络环境下不可用，可指定国内镜像。编辑如下文件：

%LOCALAPPDATA%\zbuild\runtime-config.json {"mirrorBase": "https://registry.npmmirror.com/-/binary/"}

镜像地址必须以 https:// 开头；版本、文件名与校验值无法通过配置修改，仅能覆盖镜像前缀。

方式四：使用系统已安装的 Python

如果你本机装有 Python 3.11.9（x64），可在如下文件写入其绝对路径，工具将优先使用它：

%LOCALAPPDATA%\zbuild\runtime-config.json {"overridePython": "C:\\Python311\\python.exe"}

注意：工具会校验该路径的版本号是否为 3.11.9，不匹配时不会采用。

以上任一种方式完成后，请重新打开工具。
